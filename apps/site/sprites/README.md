# Спрайты человечков

Все пиксели человечков (и дверей сцены, `door.aseprite`) лежат в `*.aseprite` этой папки и правятся в Aseprite. В dev-режиме (`pnpm --filter site dev`) сохранение файла сразу пересобирает `walkerSprite.ts` виджета человечков (`layers/pages/app/components/twitch-dudes-widget/_utils/`, руками не правится), превью всех вариантов — `http://localhost:3000/walker-preview`. Без dev-сервера — `pnpm --filter site sprites`. Генератор — `scripts/generate-walker.mjs`. Код рисует только обводку (контур в 1 пиксель вокруг всей фигуры): в файлах она не нужна.

Перекрашиваемые части рисуются цветами-ключами из палитры файла (у ключей в названии `(key)`): рубашка, волосы, штаны, обувь, аксессуар и их тени/блики — в игре они заменяются цветами зрителя. Любой другой цвет рисуется как есть, новые цвета можно брать свободно.

- `body.aseprite` (12×22) — тело без головы, по кадру на уникальную позу. Теги — анимации: `walk` (стоит + 4 кадра шага), `hold` (то же с табличкой), `front` и `wave` (анфас: стоит, машет), `front-hold` и `wave-hold` (то же с табличкой), `phone` (2 кадра мерцания экрана). Рисуется только взгляд вправо, влево — зеркало. Слои:
  - `body` — голое тело;
  - `hand` — поднятая рука (тоже голая): в отличие от `body`, рисуется поверх аксессуаров;
  - группы `pants`, `shoes`, `tops` — варианты одежды, каждый слой — вещь целиком; на человечке всегда по одной вещи из группы, поверх тела в порядке групп. Первый слой группы — базовый вариант (джинсы, ботинки, лонгслив), остальные в игре хранятся как разница с ним. Новый слой в группе — новый вариант одежды. Вещь не должна заходить на пиксели, где причёски различаются, — генератор проверит и скажет;
  - `anchor` — ровно один пиксель на кадр: куда ставится левый верхний угол головы (и аксессуаров);
  - `_head` — полупрозрачная голова для ориентира, в спрайт не попадает.
- `heads.aseprite` (24×10) — по кадру на причёску, имя — тег кадра. Слева голова сбоку (смотрит вправо), справа анфас. Нижняя строка — шея: выше неё голова кивает, когда человечек говорит. Кадр `robot` — голова робота для чат-ботов; тело робота — то же тело, перекрашенное в металл.
- `accessories.aseprite` (24×22) — по кадру на аксессуар, имя — тег, порядок кадров — порядок отрисовки. Слева вид сбоку, справа анфас (пустой анфас — как сбоку). Ставится в ту же точку, что голова. Головной убор прячет человечка выше строки N головы — это `cut=N` в User Data тега. Контур аксессуарам рисуется вручную. `_ref` — человечек для ориентира.

- `door.aseprite` (16×30) — дверь сцены, по кадру на положение створки: от закрытой (первый кадр, створка стоит ребром и не видна) до полностью открытой (последний). Рисуется левая дверь — косяк у левого края, створка на петлях у него; правая — зеркало. Открываясь, дверь проходит кадры по порядку и в конце чуть «перелетает» (предпоследний кадр, затем последний), закрываясь — идёт обратно. Обводки нет, слои просто складываются. Порядок кадров и длительность анимации заданы в `SceneDoor.vue`, длительности кадров в файле не используются.

Слои-ориентиры — reference-слои Aseprite (в свойствах слоя), генератор их пропускает; скрытые слои он не пропускает.
