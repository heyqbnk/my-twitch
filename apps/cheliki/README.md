# cheliki

Сцена с человечками из чата Twitch: автор сообщения выходит куклой 64px из `public/paper-doll/` и бродит по низу экрана.

## Страницы

- `/?channel=<канал>` — сцена настоящего чата. Над головой человечка — ник и облачко с сообщением на 6 секунд. Код — в `src/doll-chat/`.
- `/playground.html` — песочница для всех фич без настоящего чата: выдуманные зрители с ролями, подпиской, фолловом и ручной внешностью пишут сообщения (выделенные, ответы, упоминания, `bb`, `!vanish`), модерация (удалить сообщение, таймаут, очистить чат) и настройки сцены — масштаб, пол, `stay`, `msg_delay`, фон, эмодзи 7TV/BTTV с настоящего канала. Сообщения собираются из IRC-тегов тем же `toChatMessage`, что и в чате. Зрители и настройки запоминаются в `localStorage`. Код — в `src/playground/`.

Анимации нарисованы только влево, вправо — зеркально. Одежда, обувь, волосы и глаза — отдельные картинки на каждый кадр, рисуются поверх тела; серые слои умножаются на цвет. Кукла описана в `src/doll/doll64.ts`, остальной код куклы — в `src/doll/`.

## Где работает

Сцена делается для browser source в OBS. Минимальная версия браузера — Chromium 127 (CEF в
OBS 32.2): она указана в `browserslist` в `package.json` и в `build.target` в `vite.config.ts`.
Перемены в анимациях и стилях проверяй в самом OBS — встроенный Chromium иногда ведёт себя иначе,
чем Chrome.

## Параметры

Задаются в адресе страницы, например `?channel=qbnk&scale=3&stay=10`.

| Параметр  | Значение                     | По умолчанию     | Описание                                                                                   |
|-----------|------------------------------|------------------|--------------------------------------------------------------------------------------------|
| `channel` | логин канала (`a-z0-9_`, до 25 символов) | —      | Обязательный. Чей чат слушать; регистр и `#` в начале игнорируются                         |
| `scale`   | целое от 1 до 10             | `2`              | Размер человечков: сколько экранных пикселей на один пиксель спрайта |
| `ground`  | целое от 0 до 64             | `8`              | Высота пола в пикселях сцены (в экранных — умножить на `scale`); `0` — без пола            |
| `stay`    | минуты, > 0 (можно дробное)  | без ограничения  | Сколько человечек остаётся на сцене после своего последнего сообщения                      |
| `msg_delay` | секунды, ≥ 0 (можно дробное) | `0`              | Задержка показа сообщения; удалённое модератором за это время (или автор забанен/в таймауте) не показывается |

Некорректное значение `scale`, `ground`, `stay` или `msg_delay` заменяется значением по умолчанию; без корректного `channel` вместо сцены показывается подсказка.

## Команды в чате

- `!vanish` — человечек исчезает со сцены; сама команда не показывается.
- `bb` / `бб` — то же самое, но только если это всё сообщение целиком и не ответ на чужое сообщение.

## Внешность

У каждого человечка своя внешность, одинаковая в разных сессиях (выбирается по Twitch ID):

- футболка — всегда в цвет ника;
- штаны — джинсы или шорты, у каждого свой цвет;
- обувь — ботинки, кеды, лоферы или сандалии;
- причёска и цвет волос.

Отдельным зрителям внешность меняют флаги в `src/userFeatures.json` — по логину в нижнем регистре:

```json
{ "users": { "sarorn": { "noPants": true, "noShoes": true } } }
```

- `noPants` — без штанов, голые ноги;
- `noShoes` — без обуви, босиком.

Новый флаг добавляется в `UserFeatures` (`src/userFeatures.ts`).

## Кто поверх кого

Когда человечки перекрывают друг друга, сверху оказывается тот, у кого выше приоритет (от высшего к низшему):

1. Человечек с выделенным сообщением (за баллы канала), пока висит его облачко.
2. Любой другой говорящий человечек, пока висит его облачко.
3. Молчащие человечки.

Внутри каждого пункта порядок определяется старшинством автора:

1. Владелец канала.
2. Модераторы.
3. VIP — по стажу подписки (чем дольше, тем выше; VIP без подписки ниже VIP с подпиской).
4. Подписчики — по стажу подписки.
5. Фолловеры — кто раньше зафолловил, тот выше (дата фоллова берётся из IVR).
6. Остальные зрители.

Логика — в `src/scene/actorPriority.ts`, слой человечка считается в `src/doll-chat/ChatDoll.vue`.
